CampusConnect - Web Technology Project

Folder structure follows the classroom instruction:
- Admin/ contains all Admin Side pages.
- Main project folder contains Client Side pages.
- style.css and script.js are shared by both sides.

Run: Open index.html with VS Code Live Server.
Admin: click Admin Login from the client website.
Demo username: admin
Demo password: admin123

Features: event browsing, event registration, admin event management,
registration viewing, contact message storage, and JavaScript validation
on Registration and Contact forms. Data is stored in browser LocalStorage;
this is a frontend-only demo and does not use PHP/MySQL.
